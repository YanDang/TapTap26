# gamejam · 寄居蟹战斗原型

TapTap 聚光灯 Game Jam 的**战斗玩法原型**（一个阶段性版本，不是完整游戏）。
Unity 2022.3.57f1，内置渲染管线，2D 骨骼角色放在 2.5D 场景里。

## 分工

| 角色 | 负责内容 |
|---|---|
| **策划**（本仓库作者） | 战斗系统设计与实现、角色动画（程序化动作、表情）、怪物 AI、战斗家具、自测 |
| **美术** | 主角（寄居蟹女孩）和怪物（鱿鱼）的原画与 PSB 骨骼模型 |
| **程序** | 采集与合成系统（家具蓝图 / 材料，在另一个工程里，**不在本仓库**） |

代码在 Claude Code（AI 编程助手）辅助下编写。

## 怎么玩

用 Unity 打开工程，打开 `Assets/Scenes/Main.unity`，点 Play。只用鼠标两个键：

| 操作 | 非战斗 | 战斗中 |
|---|---|---|
| 右键点敌人 | 锁定，自动追击、自动普攻，进入战斗 | 切换目标 |
| 右键点地面 | 走过去 | 缩壳翻滚 → 机械臂从壳口伸出一拳 → 钻出壳、退出战斗（CD 5 秒）；CD 中则直接走开并退出战斗 |
| 左键短按 | 桌子旁：踢桌子 | 黄光窗口内 = 格挡；待处决的敌人 = 处决；桌子旁 = 踢桌子；否则空挡（格挡 CD 0.5 秒） |
| 左键按住 | — | 蓄力（屏幕任意位置，可打断普攻），松开前扑砸地，蓄满伤害 4 |

### 主角（寄居蟹女孩）
- **普攻三连**：钳子横扫 → 钳子直戳 → 前腿踩踏。
- **蓄力砸击**：越蓄越抖，蓄满半径 2.1 m。
- **格挡**：转身用背上的贝壳挡。
- **缩壳翻滚 + 伸臂重拳**：其他图层隐藏只留壳滚出去，机械臂沿伸缩杆打出，收拳后 0.3 s 钻出壳（期间不能操作）。
- **表情**：普攻 / 蓄力 / 处决 = 愤怒；受击 / 被缠 / 被丢 = 痛苦（`> <`）；打倒敌人随机高兴（`^ ^`）。
- 动作全部是脚本驱动的（IK + 关键帧 + 弹簧骨），见 `Scripts/Hero2D/`。

### 怪物（鱿鱼）
- **黄光 = 普通攻击**：可格挡，格挡成功后世界 0.1 倍速 3 秒，再点左键处决。
- **红光一直闪 = 抓取**：前摇 1.5 s 触手狂舞，不能格挡、只能躲；缠住 3 s 每秒扣 1 血，然后把主角丢出去 3 m，躺地后 0.5 s 慢慢起身。被缠期间其他怪不攻击。
- **目标规则**：被嘲讽 → 打嘲讽家具；检测范围内有玩家 → 打玩家；否则去打附近的家具，锁定家具后打到坏为止，不理玩家。

### 战斗家具（来自合成系统的“杂交废料”，都不伤主角）
| 家具 | 效果 |
|---|---|
| 膨胀的气囊疙瘩 | 敌人走进范围（或打它）→ 鼓胀 0.35 s → 范围爆炸 + 眩晕 |
| 抽搐的痉挛金属团 | 敌人踩上去被弹飞 3 m + 麻痹 |
| 漏电的烂泥珊瑚块 | 带电泥潭：减速 45%，每秒电一下 |
| 嘶鸣的过载排气瓣 | 间歇尖啸，7 m 内的怪被强行吸引过去打它 |
| 活性共生杂交残渣 | 会自愈的路障，打碎后分裂成减速碎块 |

家具贴图暂时借用合成系统的材料图标，之后替换 `Assets/Resources/Furniture/` 里同名的 png 即可。

## 自测

进 Play 模式后点菜单 **GameJam → Run Self Test (Play mode)**，结果写到工程根目录 `selftest.txt`（当前 80 项全部通过）。
覆盖：移动、锁敌、格挡 / 慢动作 / 处决、翻滚重拳、蓄力、钟表 QTE、踢桌子、鱿鱼抓取、5 种家具、怪物目标规则等。

## 常用编辑器菜单
- **GameJam → 表情调整**：Play 模式下手动微调表情贴片的位置，保存到 `face_tweaks.json`。
- **GameJam → Hero2D → Record Combat Actions**：录一段主角战斗动作的演示帧到 `Temp/HeroActs/`。
- **GameJam → Hero2D → Shoot Faces** / **GameJam → Furniture → Shoot Overview**：拍表情特写、家具摆放截图。

## 代码结构（`Assets/Scripts`，命名空间 GameJam）
- `Combat/`：PlayerController（主角状态机）、EnemyAI（鱿鱼 AI、抓取、目标选择）、CombatFurniture 及各家具、KickableTable、Unit
- `Hero2D/`：HeroActions（战斗动作层）、HeroGait（步态）、HeroSpringBones（头发 / 贝壳弹簧）、HeroFace（表情）、HeroBlink（眨眼）、HeroFacing（转身）
- `Squid/`：SquidAnimator（浮空、蛇舞触须、攻击、抓取）、SquidFace（愤怒脸）
- `Core/`：TimeManager（慢动作 / 时停）、CameraRig、Billboard、FaceOverlay、Sfx、Vfx
- `GameManager`：生成主角、敌人、家具、HUD；`SelfTest`：自动化测试

音效是程序合成的占位音；场景使用霓润城生态站（`Assets/SpotlightScene`）。
