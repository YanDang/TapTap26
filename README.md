# gamejam · 寄居蟹战斗原型

TapTap 聚光灯 Game Jam 的**战斗玩法原型**（一个阶段性版本，不是完整游戏）。
Unity 2022.3.57f1，内置渲染管线，2D 骨骼角色放在 2.5D 场景里。

## 分工

| 角色 | 负责内容 |
|---|---|
| **策划**（本仓库作者） | 战斗系统设计与实现、角色动画（程序化动作、表情）、怪物 AI、战斗家具、自测 |
| **美术** | 主角（寄居蟹女孩）和怪物（鱿鱼）的原画与 PSB 骨骼模型 |
| **程序** | 采集与合成系统（家具蓝图 / 材料，在另一个工程里，**不在本仓库**） |

代码在 Claude Code（AI 编程助手）辅助下编写。

## 怎么玩

用 Unity 打开工程，打开 `Assets/Scenes/Main.unity`，点 Play。只用鼠标两个键：

| 操作 | 非战斗 | 战斗中 |
|---|---|---|
| 右键点敌人 | 锁定，自动追击、自动普攻，进入战斗 | 切换目标 |
| 右键点地面 | 走过去 | 缩壳翻滚 → 机械臂从壳口伸出一拳 → 钻出壳、退出战斗（CD 5 秒）；CD 中则直接走开并退出战斗 |
| 左键短按 | 桌子旁：踢桌子 | 黄光窗口内 = 格挡；待处决的敌人 = 处决；桌子旁 = 踢桌子；否则空挡（格挡 CD 0.5 秒） |
| 左键按住 | — | 蓄力（屏幕任意位置，可打断普攻），松开前扑砸地，蓄满伤害 4 |

### 主角（寄居蟹女孩）
- **普攻三连**：钳子横扫 → 钳子直戳 → 前腿踩踏。
- **蓄力砸击**：越蓄越抖，蓄满半径 2.1 m。
- **格挡**：转身用背上的贝壳挡。
- **缩壳翻滚 + 伸臂重拳**：其他图层隐藏只留壳滚出去，机械臂沿伸缩杆打出，收拳后 0.3 s 钻出壳（期间不能操作）。
- **表情**：普攻 / 蓄力 / 处决 = 愤怒；受击 / 被缠 / 被丢 = 痛苦（`> <`）；打倒敌人随机高兴（`^ ^`）。
- 动作全部是脚本驱动的（IK + 关键帧 + 弹簧骨），见 `Scripts/Hero2D/`。

### 怪物（鱿鱼）
- **黄光 = 普通攻击**：可格挡，格挡成功后世界 0.1 倍速 3 秒，再点左键处决。
- **红光一直闪 = 抓取**：前摇 1.5 s 触手狂舞，不能格挡、只能躲；缠住 3 s 每秒扣 1 血，然后把主角丢出去 3 m，躺地后 0.5 s 慢慢起身。被缠期间其他怪不攻击。
- **目标规则**：被嘲讽 → 打嘲讽家具；检测范围（7 m）内有玩家 → 打玩家；否则去打附近（9 m）的家具，锁定家具后打到坏为止，不理玩家。
- **放弃追击**：追玩家追到离主角超过 10 m（`chaseGiveUpRange`）就不追了，转去打 20 m 内最近的家具。
- **被挡路**：走路被珊瑚墙 / 共生残渣挡住走不动，转头打挡路的那件。

### 采集 / 合成（接入程序同学的 TapTap26，2026-10-11）
按 **B / Tab** 或点物品栏左边的 **合成工坊** 按钮：战斗暂停，叠加打开程序同学的**背壳工坊**（Mix 场景）。
- 工坊里点 **采集温室** 去采材料（Collect 场景：点或按住左键划过材料即可采下，进背壳背包），再点 **前往背壳工坊** 回来。
- 在背壳背包里按住左键把相邻材料连成一条线松开 = 合成；配方、品质（粗糙 / 精制 / 多孔过载）都按程序同学的规则（`ShellCraftingRecipe`）。
- **ESC / B / 返回战场** 回到战斗。合成出的成品进**合成仓库**，物品栏直接显示（家具和废料都能摆）。仓库和背包存在 PlayerPrefs，跨局保留。
- 气泡悬浮软床、高压喷水炮能合成，但战斗效果还没做（物品栏里显示为灰色、不能摆）。
- 代码在 `Assets/Crafting/`（程序同学的 13 个核心脚本 + 资源 + Mix / Collect 场景，保留原 GUID；去掉了对方工程的武器 / 旧材料库引用）；桥接是 `Scripts/CraftingBridge.cs`。
- 工坊里的调试键（对方自带）：R 随机加一个材料、F 填满背包、C 清空、1/2/3 换背壳。

### 场景（2026-10-11 清理）
测试场景只留地面、水渠、中央的贝壳生态站和地图边缘的石头 / 废墟墙；藻类水池、水母育苗台、苔藓、前排珊瑚、建造网格都删了（`GameJamBuilder.RemoveClutter`，只改拷贝出来的 Main.unity）。
开局场景里**没有任何家具和桌子**，全部从物品栏自己摆。**怪物只从中央的生态站里出来**（`GameManager.EnemySpawnPoint`）。

### 战斗家具（来自合成系统的“杂交废料”，都不伤主角；开局默认不摆，`GameManager.spawnGasCysts / spawnScrapFurniture` 打开）
| 家具 | 效果 |
|---|---|
| 膨胀的气囊疙瘩 | 敌人走进范围（或打它）→ 鼓胀 0.35 s → 范围爆炸 + 眩晕 |
| 抽搐的痉挛金属团 | 敌人踩上去被弹飞 3 m + 麻痹 |
| 漏电的烂泥珊瑚块 | 带电泥潭：减速 45%，每秒电一下 |
| 嘶鸣的过载排气瓣 | 间歇尖啸，7 m 内的怪被强行吸引过去打它 |
| 活性共生杂交残渣 | 会自愈的路障，打碎后分裂成减速碎块 |

### 正式家具（合成系统的 4 个正式蓝图，都不伤主角；从物品栏 4–7 号格自己摆）
| 家具 | 效果 |
|---|---|
| 电鳗电机发电机组 | 充能 3 s，范围 2.2 m 内有敌人就放电：1 伤害 + 麻痹 1 s；**湿身的敌人多受 1 点** |
| 增生珊瑚管排墙 | 2.6 m 长的掩体墙（挡怪也挡人），每 4 s 自愈 1 点、**在水汽里快一倍**；**只有敌人打墙时才反伤**（打墙的那只受 1 点） |
| 脉动造水循环塔 | 有节律地泵水，3.2 m 水渍：减速 45% + 淋湿 3 s |
| 小型生体驯化培养箱 | 4.5 m 内的怪慢慢被安抚（约 3 s）→ 5 s 不攻击、走到箱子旁发呆（头上显示“安抚”），挨打立刻醒，醒后 4 s 内不会再被安抚 |

家具贴图暂时借用合成系统的材料图标，之后替换 `Assets/Resources/Furniture/` 里同名的 png 即可。

### 气系生产线 + 物品栏（生产功能）
屏幕下方是物品栏（10 格，只显示手上有的物品，右边显示负重，左边是合成工坊按钮）。按 **1–9 / 0** 或点格子选中物品进入摆放模式，右键 / Esc 取消。

**放置动作**：左键后主角播 1 秒的放置动作（钳子伸进壳里掏 → 举起家具胶囊 → 往前一抛），抛出前被打 / 被抓就取消并退还物品。
**部署动画**（所有家具共用，`FurnitureDeploy`）：胶囊沿抛物线飞到落点 → 落地尘土 + 一圈冲击波 → 家具从地里弹出来（拉长 → 压扁回弹），范围圈 / 水渍从中心铺开。部署完成前家具不起作用、怪物也不会打它。点击到完全可用约 1.4 秒。
**珊瑚墙接墙**：鼠标靠近已有墙的一头会自动吸附接上（默认顺着延伸，滚轮拐弯 45° / 90°），预览线变青色；墙和墙不能重叠。
有作用范围的家具（发电机 / 水塔 / 培养箱），虚影下面会画出范围圈。**珊瑚墙**默认横在“主角 → 鼠标”方向上（挡在主角前面），**滚轮**每格转 45°；离墙的两头太近也放不下。玩家摆的家具坏了就没了（不重生）。

| 物品 | 作用 |
|---|---|
| 气旋喷口 | 气源，每秒产气（左键放下） |
| 充气导管 | 在一个气系家具上按住左键拖到另一个上松开，连上管道；每 2 米 1 根，最长 6 米，不能穿墙 |
| 气泡囊 | 储气，越充越鼓；充满后负重上限 +10；储气越多嘲讽范围越大，吸引怪物 |

- 管道连在一起的家具组成一个网络，共享气体；管道断了网络就被切开。
- 气系家具**没有伤害**，被玩家（攻击 / 在旁边点左键踢）或怪物打破时“气爆”，把周围的玩家和怪物弹开（气泡囊储气越多弹得越远）。
- 现在还没有采集系统，开局送 2 个喷口、3 个气泡囊、10 根导管、2 张桌子；正式家具和废料要去合成工坊做（基础负重 40）。

## 自测

进 Play 模式后点菜单 **GameJam → Run Self Test (Play mode)**，结果写到工程根目录 `selftest.txt`（当前 171 项全部通过；自测前会备份并清空合成仓库 / 背包，结束时还原）。
覆盖：移动、锁敌、格挡 / 慢动作 / 处决、翻滚重拳、蓄力、钟表 QTE、踢桌子、鱿鱼抓取、5 种废料 + 4 种正式家具、怪物目标规则（含放弃追击、被墙挡住）、气系生产线与物品栏摆放等。

## 常用编辑器菜单
- **GameJam → 表情调整**：Play 模式下手动微调表情贴片的位置，保存到 `face_tweaks.json`。
- **GameJam → Hero2D → Record Combat Actions**：录一段主角战斗动作的演示帧到 `Temp/HeroActs/`。
- **GameJam → Hero2D → Shoot Faces** / **GameJam → Furniture → Shoot Overview**：拍表情特写、家具摆放截图。
- **GameJam → Furniture → Demo Gas Line**：在主角附近自动搭一条演示生产线（喷口 → 气泡囊 → 气泡囊）。

## 代码结构（`Assets/Scripts`，命名空间 GameJam）
- `Combat/`：PlayerController（主角状态机）、EnemyAI（鱿鱼 AI、抓取、目标选择、安抚）、CombatFurniture 及各家具（正式家具：EelGenerator / CoralWall / WaterTower / BioIncubator）、KickableTable、Unit；
  气系生产线：GasNode / GasVent / GasSac / GasPipe / GasNetwork（连通块 + 气体分配）、BuildController（摆放模式）
- `UI/`：HUD、InventoryBar（底部物品栏）、Inventory（物品与负重）、ClockQTE
- `Hero2D/`：HeroActions（战斗动作层）、HeroGait（步态）、HeroSpringBones（头发 / 贝壳弹簧）、HeroFace（表情）、HeroBlink（眨眼）、HeroFacing（转身）
- `Squid/`：SquidAnimator（浮空、蛇舞触须、攻击、抓取）、SquidFace（愤怒脸）
- `Core/`：TimeManager（慢动作 / 时停）、CameraRig、Billboard、FaceOverlay、Sfx、Vfx
- `GameManager`：生成主角、敌人、家具、HUD；`SelfTest`：自动化测试

音效是程序合成的占位音；场景使用霓润城生态站（`Assets/SpotlightScene`）。
